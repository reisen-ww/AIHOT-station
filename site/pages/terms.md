# 使用规则

页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。阅读无需注册；可用的机器读取方式以 Agent 接入页列出的实际出口为准。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 内容版本与历史反馈

本站内容以当前发布的静态版本为准。已下载的文件是当时的快照，不会随站点更新自动替换。

读者端反馈功能已取消，当前静态站不接收新反馈。取消入口不会自动删除历史反馈业务数据或旧浏览器草稿；这些记录不导出到公开静态站。

## 3. 使用本站的数据

能够读取、订阅或下载本站文件，不代表获得第三方内容的转载、商用或再分发许可。相关内容的权利和使用条件仍由权利人及适用的许可决定，本站不代替第三方授予权利。

## 4. 公开出口与读取

公开出口用于读取当前发布的内容。静态站提供文件快照、RSS 与 Markdown，不执行在线 MCP 或参数化 REST 请求；动态部署的能力以其接入说明为准。读取时请遵循出口说明与响应中的缓存信息，避免混用不同版本的文件。

## 5. 内容局限

本站按“现状”提供，不保证内容完整、准确和持续可用。
